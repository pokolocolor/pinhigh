# 핀하이 정모 방뽑기

모바일에 최적화된 GitHub Pages용 정모 스크린골프 방 배정 웹앱입니다.

## 주요 기능
- 방 번호 입력 시 모바일 숫자 키패드 사용
- 방 등록 후 `1번 방` 형태로 표시
- 좌타방 / 좌타자 지정
- 참가자 등록 및 삭제
- 참가자 DB 자동 저장: 한 번 등록한 사람은 다음 모임에서 이름을 눌러 빠르게 재등록
- 참가자 DB는 모임 초기화 시에도 유지
- 랜덤 방배정 시 모든 방에 반드시 2~3명 배정
- 방/참가자 수가 조건에 맞지 않으면 알림으로 안내
- 데이터는 브라우저 `localStorage`에 저장
- GitHub Pages에서 별도 서버 없이 실행 가능

## GitHub Pages
1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. `main` / `/(root)`를 선택합니다.
5. 저장하면 GitHub Pages에서 실행할 수 있습니다.

## 방 배정 조건
방이 N개라면 참가자는 최소 `2N명`, 최대 `3N명`이어야 합니다.
예: 방 5개 → 참가자 10~15명.

## 데이터 초기화
상단 ↻ 버튼은 현재 모임의 방과 참가자만 초기화하며, 참가자 DB는 유지합니다.
