# 핀하이 정모 방뽑기

모바일에 최적화된 스크린 골프 정모 랜덤 방배정 웹앱입니다.

## 기능
- 방 번호 등록 / 삭제
- 좌타방 지정
- 참석자 등록 / 삭제
- 좌타자 지정
- 랜덤 방배정
- 등록 데이터 브라우저 `localStorage` 자동 저장
- 모바일 반응형 UI

## GitHub Pages 배포
1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. 저장소 **Settings → Pages**에서 `Deploy from a branch`를 선택합니다.
3. Branch는 `main`, Folder는 `/ (root)`로 설정합니다.
4. 저장하면 GitHub Pages 주소가 생성됩니다.

`index.html`이 루트에 있으므로 별도의 빌드 과정이 필요 없습니다.
