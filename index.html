GitHub 자동저장 설정 (관리자 1회)

모든 사용자는 GitHub의 공개 DB를 읽습니다. 신규 참가자 자동등록은 GitHub 쓰기 권한이 있는 관리자 브라우저에서 동작합니다. Fine-grained Token은 Contents: Read and write 권한이 필요하며 저장소에는 업로드되지 않습니다.

아직 저장된 참가자가 없습니다.

모든 방은 반드시 2명 또는 3명으로 배정됩니다.

사용 방법

  1. 방 번호를 입력하면 모바일에서는 숫자 키패드가 표시됩니다.
  2. 방은 등록 후 “1번 방”처럼 표시됩니다.
  3. 참석자는 이름만 입력합니다. 처음 등록한 이름은 GitHub 공유 DB에 자동 등록됩니다.
  4. 방 수와 참석자 수가 맞아야 랜덤 방배정이 가능합니다.
  5. 배정 결과는 모든 방에 2~3명이 들어가도록 생성됩니다.
  6. 방 목록과 배정 결과 모두 방 번호 오름차순으로 표시됩니다.

참가자 DB는 GitHub의 data/participants.json을 공유 원본으로 사용합니다. 참가자는 이름만 저장되며, 신규 이름은 관리자 브라우저에서 GitHub에 자동 등록됩니다.
